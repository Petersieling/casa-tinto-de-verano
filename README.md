# Casa Tinto de Verano

Website van het vakantiepenthouse in Punta Prima (Costa Blanca).

De hele site staat in `index.html`: tekst, opmaak, script en logo. Er is geen build-stap nodig.

## Hosten op Cloudflare Pages

- Framework preset: geen
- Build command: leeg laten
- Build output directory: `/`

## Prijzen aanpassen

De prijslijst staat onderaan `index.html` in de lijst `PERIODES`. Eindschoonmaak, borg en minimaal verblijf staan in de sectie "Praktisch".
